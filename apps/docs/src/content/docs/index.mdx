Add two packages to your existing MSW setup:

```bash
npm install msw-panel
```

```tsx
import { createMswPanelController } from "msw-panel";
import { MswPanel } from "msw-panel/react";

const controller = createMswPanelController({ runtime: worker });

function App() {
  return (
    <>
      <Routes />
      <MswPanel controller={controller} />
    </>
  );
}
```

A floating button appears in the corner. Click it to open the panel and toggle
any handler on or off. Vue and Svelte are the planned next first-party
adapters. Solid and Angular are under consideration after that.
