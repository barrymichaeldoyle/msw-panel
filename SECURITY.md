# Security Policy

If you believe you have found a security vulnerability in `msw-panel`, please
do not open a public GitHub issue.

Report it privately to:

- hello@barrydoyle.co.za

Please include:

- A description of the issue
- Steps to reproduce or a proof of concept
- The affected package, app, or integration surface
- Any suggested mitigation if you have one

You can expect an initial acknowledgement within a reasonable time, followed by
triage and next steps once the report has been reviewed.
