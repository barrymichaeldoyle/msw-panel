# Support

Use the following channels depending on what you need:

- Bug reports: open a GitHub issue with reproduction details
- Feature requests: open a GitHub issue describing the use case
- Security concerns: follow [SECURITY.md](./SECURITY.md)
- General questions: start with the docs in [README.md](./README.md) and the
  docs site in `apps/docs`

When asking for help, include:

- Which package or example app you are using
- Your MSW version
- Your runtime environment
- A minimal reproduction when possible
